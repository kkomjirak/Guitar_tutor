Phase 1 · 1~2개월

지판 이해의 기초

기타 지판이 "어떻게 구성되어 있는지" 이해하기

1 음이름과 지판 매핑

  • 6번줄(E)과 5번줄(A)의 음이름을 먼저 외우세요
  • 바레코드의 루트, 스케일의 시작점이 모두 이 두 줄에서 출발합니다
  • 연습법: 메트로놈 60BPM에 맞춰 음이름을 말하며 한 음씩 치기

Phase 2 · 2~3개월

펜타토닉 & 블루스 — JAM의 시작

백킹트랙에 맞춰 "그럴듯한" 솔로를 시작하기
💡 핵심 TIP: 펜타토닉 스케일은 자유연주의 가장 빠른 지름길입니다. 5개 음만으로 놀라울 정도로 많은 것을 표현할 수 있습니다.

💡 마이너 펜타토닉의 "밝은 버전" — 같은 구성음이지만 루트가 다릅니다 (A 메이저 펜타 = F# 마이너 펜타)

2 실전 연습 방법

  • 좋아하는 곡의 솔로에서 펜타토닉 패턴을 찾아보세요
  • YouTube에서 "A minor backing track" 검색해서 매일 JAM
  • 12마디 블루스 진행(I-IV-V) 위에서 블루스 스케일 연습
  • 처음엔 2~3개 음만으로 리듬과 느낌에 집중하세요
  • 벤딩, 슬라이드, 비브라토를 여기서 집중 연습
⚡ 주의: 빠르게 많이 치려 하지 마세요. 적은 음으로 노래하듯이 치는 것이 훨씬 음악적입니다. 좋은 솔로는 음의 개수가 아니라 타이밍과 표현력에서 나옵니다.

Phase 3 · 3~4개월

코드 톤 & 코드 이해

"왜 이 코드 위에서 이 음이 좋게 들리는지" 이해하기

1 트라이어드 (3화음)

  • 메이저 트라이어드: 루트 + 장3도 + 완전5도 (밝은 소리)
  • 마이너 트라이어드: 루트 + 단3도 + 완전5도 (어두운 소리)
  • CAGED 시스템으로 지판 위 코드 모양을 연결하세요

2 코드 톤 어프로치

  • 코드 진행 위에서 각 코드의 구성음(코드 톤)을 노려서 치는 연습
  • 예: Am → Dm → G → C 진행에서 각 코드의 1, 3, 5도를 연결
  • 이것만 해도 "아무 음이나 치는 느낌"에서 벗어남
💡 연습법: 먼저 코드 진행을 틀어놓고, 각 코드가 바뀔 때마다 해당 코드의 루트 음만 치세요. 그 다음엔 루트 + 3도, 그 다음엔 루트 + 3도 + 5도... 이렇게 점진적으로 늘려가세요.

3 다이어토닉 코드

  • 한 키 안에서 만들어지는 7개 코드
  • 곡의 코드 진행을 번호(로마 숫자)로 이해하기 시작
  • 카피하던 곡들의 코드 진행을 다이어토닉으로 분석해보세요

Phase 4 · 6개월~

모드 & 확장

더 다양한 색깔의 사운드 만들기

1 모드 (Modes)

  • 아이오니안 (Ionian) — 메이저 스케일 그 자체, 밝고 안정적
  • 도리안 (Dorian) — 마이너 펜타 + 장6도 + 단2도. 마이너인데 밝은 느낌
  • 믹솔리디안 (Mixolydian) — 메이저인데 단7도. 블루지/록 느낌

2 7th 코드 & 확장 코드

  • 7th, 9th 코드 보이싱으로 사운드 풍성하게
  • 코드 톤 어프로치를 7th까지 확장

3 키 이동 (Transposing)

  • 같은 프레이즈/패턴을 12키 모두에서 치는 연습
  • "모양"으로 기억하면 기타에서는 의외로 쉽습니다
  • 스케일 박스를 다른 프렛으로 옮기기만 하면 키가 바뀝니다
